# Tool logos

Drop official logo files here. The site shows them automatically; any tool
without a file keeps its letter tile. Square logos look best (SVG preferred,
or PNG/WebP at 128×128 or larger).

| Tool | File name |
|---|---|
| Photoshop | `photoshop.svg` |
| Illustrator | `illustrator.svg` |
| Premiere Pro | `premiere-pro.svg` |
| After Effects | `after-effects.svg` |
| Figma | `figma.svg` |
| Canva | `canva.svg` |
| CapCut | `capcut.svg` |
| Claude | `claude.svg` |
| ChatGPT | `chatgpt.svg` |
| Codex | `codex.svg` |
| Cursor | `cursor.svg` |
| OpenCode | `opencode.svg` |
| Gemini | `gemini.svg` |
| Midjourney | `midjourney.svg` |
| Firefly | `firefly.svg` |

Get each logo from the company's brand / press kit page and follow its usage guidelines.
After adding files, restart `npm run dev` (or rebuild) so they get picked up.
